**[Oravan](https://oravan.org)** · [code](https://github.com/cm2489/oravan)  
A free, nonpartisan guide to Congress in English and Spanish: find your members, read active bills in plain language, and make the call.

- A nightly pipeline turns official Congress.gov records into plain-language summaries, labels AI-written text where it first appears, and commits nothing when a check fails.
- A public MCP server: five tools, no key, listed in the official MCP Registry.
- About 7,500 prerendered pages. No accounts, no cookies, no trackers.
